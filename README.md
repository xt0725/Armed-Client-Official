About Armed Client
Armed Client is an independent Windows launcher for Roblox, designed around a modern interface, convenient launch controls, and customizable settings. This repository hosts official public downloads and release notes only. The development source code is kept in a separate private repository.
Features
Launch Roblox and Roblox Studio from one interface.
Visual presets to adjust supported graphics-related settings.
Discord Rich Presence integration, with optional account-related features.
Home dashboard with launch shortcuts and update information.
Update checks and integrity verification in supported versions.
Dark Windows interface with Armed Client branding.
Actual features depend on the installed version. Visual presets do not guarantee FPS improvements, and Roblox may ignore some settings.
Download & installation
Go to the latest release.
Under Assets, download `ArmedClient-Setup.exe`.
Close Armed Client if it is running, then launch the installer.
Follow the on-screen installation steps.
Requirements: Windows 10 or 11, 64-bit; internet access for Roblox services.

Development and updates
Armed Client is in active development. Read the release notes for changes and known issues. The v0.3.8 installer may still check the former private source repository for updates. A future fixed installer will switch to this public release feed; users of v0.3.8 will need to install that fixed version manually once.
