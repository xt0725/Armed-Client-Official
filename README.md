## About Armed Client

Armed Client is an independent Windows launcher for Roblox, designed around convenient launch controls and customizable settings. This public repository hosts downloads and release notes. Source code is maintained privately.

## Features

- Launch Roblox and Roblox Studio.
- Visual profiles for supported graphics-related settings.
- Optional Discord Rich Presence integration.
- Home dashboard with launch shortcuts and update information.
- Update checks and download integrity verification in supported builds.
- Dark Windows interface with Armed Client branding.

Actual features vary by version. Graphics presets do not guarantee FPS gains.

## Download and installation

1. Open the [latest release](https://github.com/xt0725/Armed-Client-Official/releases/latest).
2. Under **Assets**, download `ArmedClient-Setup.exe`.
3. Close Armed Client if it is running, then run the installer.

**Requirements:** Windows 10 or Windows 11, 64-bit.
